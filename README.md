# ZUPIUM AI

**ZUPIUM** adalah AI assistant berbasis web yang dirancang untuk membantu pengguna dalam berbagai kebutuhan, mulai dari menjawab pertanyaan, menganalisis gambar dan dokumen, membantu pemrograman, hingga menyajikan informasi visual dari NASA. ZUPIUM menggunakan **Groq API** sebagai mesin AI dan dibangun dengan **Flask** sehingga ringan serta mudah dikembangkan dan di-deploy.

## Fitur Unggulan

* **AI Assistant**
  Menjawab pertanyaan dan membantu berbagai kebutuhan pengguna dengan respons yang ringkas, ramah, dan terstruktur.

* **Analisis Gambar**
  Dapat menerima dan menganalisis gambar menggunakan model vision AI.

* **Analisis File & Dokumen**
  Mendukung ekstraksi dan pembacaan berbagai format file, termasuk:

  * PDF
  * Word (`.docx`)
  * Excel (`.xlsx`)
  * PowerPoint (`.pptx`)
  * Berbagai file teks dan kode pemrograman

* **Programming Assistant**
  Membantu menjelaskan kode, mencari kesalahan, memperbaiki error, serta memberikan contoh kode.

* **Markdown & Syntax Highlighting**
  Jawaban AI mendukung Markdown, code block, syntax highlighting, dan tombol untuk menyalin kode.

* **NASA Earth Image**
  ZUPIUM dapat mendeteksi permintaan seperti *"gambar Bumi hari ini"* dan mengambil gambar Bumi terbaru melalui **NASA EPIC API**.

* 💬 **Riwayat Percakapan**
  Pengguna dapat membuat, berpindah, dan menghapus percakapan melalui sidebar.

* 📎 **File Attachment**
  Pengguna dapat melampirkan file langsung melalui antarmuka chat.

* ⚡ **Streaming Response**
  Respons AI dapat ditampilkan secara bertahap sehingga terasa lebih cepat dan interaktif.

## Tujuan Project

ZUPIUM dibuat sebagai AI assistant yang tidak hanya berfungsi sebagai chatbot biasa, tetapi juga mampu berinteraksi dengan berbagai jenis file, memahami gambar, membantu pekerjaan pemrograman, menangani rumus matematika, serta terhubung dengan sumber data eksternal seperti NASA.

Project ini juga dirancang agar dapat terus dikembangkan dengan menambahkan model AI, fitur baru, maupun integrasi API lainnya.
